# Mavis

> 你的私人 AI 助手 — 多角色群聊 / 朋友圈 / 任务管理 / 记忆库 / 提示词库

Mavis 是一款完全开源的本地 AI 聊天客户端，支持多角色群聊、AI 朋友圈、任务管理、记忆库与提示词库，所有数据保存在本地，无广告、无追踪、无 VIP。

## ✨ 功能特性

- 🗨️ **多角色群聊** — 多个 AI 角色同屏对话，互相 cue，热闹不冷场
- 📱 **AI 朋友圈** — 微信风格朋友圈，AI 自动发动态、互相点赞评论
- ✅ **任务管理** — 让 AI 帮你规划、追踪任务进度
- 🧠 **记忆库** — AI 长期记住你的偏好与重要信息
- 📚 **提示词库** — 支持正则 / 世界书 / 预设导入（兼容 SillyTavern 格式）
- 🔌 **多 API 配置** — 自由填写你的 API Key，数据不出本地
- ⚡ **流式输出** — 打字机效果，响应快
- 🎨 **自写 Markdown 渲染器** — 表格、代码块、引用全支持

## 📥 下载安装

- 最新版本：前往 [Releases](https://github.com/hfhfjdb1/Mavis/releases) 下载 APK
- 要求：Android 7.0+

## 🚀 快速开始

1. 安装 APK 后打开应用
2. 进入「我的」→「API 配置」，填入你的 API Key 与接口地址
3. 开始聊天！

支持任意 OpenAI 兼容接口（含各种中转站）。

## 📦 导入功能

- **角色卡**：支持 SillyTavern chara_card_v2 / v3 格式（`.json`）
- **预设**：支持 SillyTavern 预设导出格式（`prompts` + `prompt_order`）
- **世界书**：自动按分组导入

## 🛠️ 技术栈

- 原生壳：Android WebView（安全加固：URL 白名单、禁用文件访问、禁明文流量）
- 前端：原生 HTML/CSS/JS（零依赖，约 3000 行）
- 存储：localStorage 本地存储
