📱 下载安卓 App
方式一：PWA 直接安装（推荐）
用 Chrome / Edge 浏览器打开本页面，即可一键安装到桌面，体验接近原生 App。
1安卓 Chrome 打开本页地址
2点右上角 ⋮ 菜单
3选「添加到主屏幕 / 安装应用」
4桌面出现 Mavis 图标，点开即可
或
方式二：打包成 APK 安装包
用 PWABuilder 把本站打包成 .apk，安装到任意安卓手机（无需浏览器）。
1复制下方站点地址
2打开 pwabuilder.com，粘贴地址
3点 Generate → 选 Android
4下载 .apk，传到手机安装
